# 久沃 AI 接線生（測試版）

瀏覽器端的餐廳 AI 接線生示範：用麥克風或打字完成訂位流程。語音辨識與語音回覆都走瀏覽器內建 API，對話大腦是規則式狀態機，不需登入或 API 金鑰。

## 使用方式

1. 用電腦版 Chrome 或 Android Chrome 打開網站（效果最佳）。
2. 允許麥克風權限。
3. 按住中間按鈕說話，或點一下開始／停止；也可以用下方欄位打字測試。
4. 可一次說完整資訊，例如：「我要訂明天晚上七點四個人」。

本機預覽（不要直接用 file:// 開，否則麥克風通常會被擋住）：

```bash
cd ai-receptionist-demo
python3 -m http.server 8080
```

然後打開 http://localhost:8080

## 已知限制

- 這是規則式對話引擎，不是 GPT。
- iOS Safari 的語音辨識支援不完整，建議改用 Chrome。
- 營業時間、地址、包廂、停車、素食為示範資料，訂位不會寫入真實系統。
